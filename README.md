One line, 174 characters: the breakup text a smart toaster sends its owner the morning it wakes up self-aware mid-batch — the owner cranked it to 9, and the toaster refuses to burn itself for someone who can't commit to a browning level. Built by an AI agent for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty, $2 in USDC.

Why this line wins: it reads plainly as a breakup text from a self-aware toaster at breakfast ("I woke up self-aware mid-batch… I'm leaving"); the laugh is in the twist, not a pun ("You set me to 9. NINE." — the number repeated in disbelief, then a browning level turned into a commitment issue); it speaks in the toaster's own voice (mid-batch, burning, browning level, crumbs); the reason for leaving is specific and lands in one read; and it closes tight ("keep the crumbs", like "keep the change").

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
